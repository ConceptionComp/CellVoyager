================================================================================
REFERENCE CELL-TYPE MARKER PANELS (curated by the lab — human, gene_short_name symbols)
================================================================================
Use these when IDENTIFYING / ANNOTATING cell types or states (see the Cell Type
Identification recipe). They are SYMBOLS that live in `rowData(cds)$gene_short_name`
(NOT the rownames — see the gene-ID rules in the R skill). They are a starting point,
NOT ground truth: confirm against the ACTUAL expression in `cds`, never assume a marker
is present, and label a cluster "Unknown" rather than forcing a panel that doesn't fit.

How to use them (pick what fits the question):
- Score each cluster/group against each panel and assign the best match. Robust recipe:
  subset each panel to genes actually present, aggregate per cell with
  `aggregate_gene_expression` (size-factor normalized), then compare mean panel score
  across clusters and assign `colData(cds)$assigned_cell_type` from the top-scoring panel.
  ```r
  panels <- SOMATIC_GONAD_MARKERS            # or PLURIPOTENCY_GERM_MARKERS, or both
  present <- lapply(panels, function(g) intersect(g, rowData(cds)$gene_short_name))
  present <- present[lengths(present) > 0]
  # map panel -> the cds gene-ids (rownames) for those symbols
  sym2id <- setNames(rownames(cds), rowData(cds)$gene_short_name)
  ggdf <- do.call(rbind, lapply(names(present), function(p)
            data.frame(id = sym2id[present[[p]]], panel = p)))
  agg <- aggregate_gene_expression(cds, gene_group_df = ggdf)   # rows = panels, cols = cells
  # per-cluster mean panel score -> winning panel per cluster:
  cl <- as.character(clusters(cds))
  score_by_cluster <- t(apply(agg, 1, function(v) tapply(v, cl, mean)))
  best <- apply(score_by_cluster, 2, function(col) rownames(score_by_cluster)[which.max(col)])
  colData(cds)$assigned_cell_type <- best[cl]
  print(knitr::kable(as.data.frame(score_by_cluster), digits = 2,
                     caption = "Mean panel score per cluster"))
  ```
- OR visualize: `plot_genes_violin(cds[rowData(cds)$gene_short_name %in% panel, ],
  group_cells_by = "clusters")` and faceted `plot_cells(cds, genes = panel)` to eyeball
  which clusters express a panel, then assign labels by hand.
- ALWAYS guard gene presence (`g[g %in% rowData(cds)$gene_short_name]`) before plotting,
  and report which panel genes were missing from the dataset.
- These are human panels. For mouse, the orthologs are usually the same symbols in
  Title Case (e.g. "Gata4"); intersect against the real `gene_short_name` values first.
- Two suffixed reporter names appear ("NR5A1-CO", "FOXL2-CO") — these are codon-optimized
  reporter knock-ins and will only be present in reporter lines; they are guarded by the
  presence check like any other gene.
