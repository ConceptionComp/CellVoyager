All code below is R, executed through monocle3 (via rpy2 `%%R` cell magic). The data handle is the R object `cds`, a Monocle3 `cell_data_set` (an extension of `SingleCellExperiment`). It is already loaded in memory. Access its parts with R accessors: `colData(cds)` (cell metadata), `rowData(cds)`/`fData(cds)` (gene metadata), `reducedDims(cds)` (embeddings), `assay(cds, "counts")`/`exprs(cds)` (expression matrices), `dim(cds)` (returns `[genes, cells]`).

## Preprocessing
Purpose: Normalize, log-transform, and reduce the data to a low-dimensional PCA space that downstream steps build on.
preprocess_cds: `cds <- preprocess_cds(cds, num_dim = 50, method = "PCA")` normalizes (log + size-factor) and computes the top principal components, stored in `reducedDims(cds)[["PCA"]]`. Use `method = "PCA"` (default) or `"LSI"`. Inspect explained variance with `plot_pc_variance_explained(cds)`. Batch effects can be removed afterward with `cds <- align_cds(cds, alignment_group = "<batch_column>")`, which writes an `"Aligned"` reduced dim that later steps will pick up automatically. Note: a CDS read from an existing `.RDS` may already be preprocessed/aligned — check `reducedDimNames(cds)` before recomputing.

## Dimensionality Reduction
Purpose: Embed cells into 2D/3D for visualization and as the basis for clustering.
reduce_dimension: `cds <- reduce_dimension(cds, reduction_method = "UMAP")` builds a UMAP embedding (default) from the PCA/Aligned space, stored in `reducedDims(cds)[["UMAP"]]`. `reduction_method = "tSNE"` is also available. Control it with `umap.n_neighbors`, `umap.min_dist`, `preprocess_method = "PCA"` or `"Aligned"`. Visualize with `plot_cells(cds)`. Reduction requires `preprocess_cds` to have run first.

## Clustering
Purpose: Identify groups of similar cells (cell types or states) in an unsupervised way.
cluster_cells: `cds <- cluster_cells(cds, k = 15)` runs Leiden/Louvain community detection on the UMAP space and assigns each cell a cluster (`clusters(cds)`) and a partition (`partitions(cds)`). This lab tunes the nearest-neighbor count `k` (typical k≈12–35; higher k → fewer/coarser clusters) rather than `resolution`, and stores the result as a column: `colData(cds)$clusters <- as.character(clusters(cds))`. It depends on `reduce_dimension`. Retrieve labels with `clusters(cds)` or color them via `plot_cells(cds, color_cells_by = "clusters")`. Partitions are coarse groupings used by trajectory learning. ⛔ DO NOT re-cluster if clustering is already available: first check `clusters(cds)`/`partitions(cds)` and the colData annotation columns — if clusters, partitions, or a cell-type annotation already exist (they are retained on subsets), REUSE them instead of calling `cluster_cells` again. Re-clustering discards curated, paper-consistent labels and renumbers clusters arbitrarily. Only call `cluster_cells` when a step that strictly needs partitions (e.g. `learn_graph`) has none.

## Marker Gene Detection
Purpose: Identify genes that distinguish clusters or annotated groups.
top_markers: `marker_test <- top_markers(cds, group_cells_by = "clusters", genes_to_test_per_group = 15, speedglm.maxiter = 100)` returns a data.frame of the most specific marker genes per group, ranked by `marker_score`/`specificity` with `pseudo_R2` and `marker_test_p_value`. `group_cells_by` must be a column in `colData(cds)` — prefer the pre-stored `clusters` or `assigned_cell_type`. Lab idiom: filter `fraction_expressing >= 0.10`, then `dplyr::group_by(cell_group) %>% arrange(desc(marker_score))` and take the top few per group. Visualize the chosen markers with faceted feature plots (`plot_cells(cds, genes = ...)`) and violin plots (`plot_genes_violin(cds[gene_rows, ], group_cells_by = "clusters")`), and tabulate with `knitr::kable`. Results are returned, not stored on the object.

## Cell Type Identification / Annotation
Purpose: Assign biological identities (cell types/states) to cells when the dataset has NONE already. ALWAYS check first — `print(colnames(colData(cds)))` and inspect for an existing annotation column (e.g. `cell_type`, `assigned_cell_type`). If a good annotation already exists, reuse it and do NOT redo this. But if none exists (common for single-sample datasets), identifying cell types is itself a strong, high-value analysis — it grounds every downstream comparison, and a trajectory/module analysis on unlabeled clusters is far less interpretable. Recommended recipe using only the available packages:
1. Cluster: `cds <- cluster_cells(cds, k = 15)` (tune `k` to a biologically sensible number of clusters; inspect `table(clusters(cds))`) — but only if no usable clustering already exists.
2. Per-cluster markers: `marker_test <- top_markers(cds, group_cells_by = "clusters", genes_to_test_per_group = 15)`; take the top markers per cluster (by `marker_score`/`specificity`) and tabulate them (knitr::kable, with `gene_short_name`).
3. Annotate each cluster: map its top markers to the CURATED REFERENCE MARKER PANELS provided in this prompt (SOMATIC_GONAD_MARKERS and PLURIPOTENCY_GERM_MARKERS — score each cluster against the panels and take the best match), and/or to known cell-type/lineage markers for the tissue, AND/OR run GO enrichment (clusterProfiler::enrichGO or gprofiler2::gost) on each cluster's markers — then assign a putative label per cluster.
4. Store the labels as a real column so downstream steps can use them: `colData(cds)$assigned_cell_type <- recode_clusters_to_labels[ as.character(clusters(cds)) ]` (a named-vector lookup from cluster id → label). Verify with `table(colData(cds)$assigned_cell_type)` and visualize with `plot_cells(cds, color_cells_by = "assigned_cell_type", label_cell_groups = TRUE)`.
Be honest about confidence: label clusters you cannot confidently identify as "Unknown" rather than guessing, and never invent marker expression — read it from the real `cds`.

## Differential Expression (regression / model-based)
Purpose: Test which genes change with a covariate of interest (condition, pseudotime, etc.).
fit_models: `gene_fits <- fit_models(cds, model_formula_str = "~condition")` fits a generalized linear model per gene; `coefficient_table(gene_fits)` returns effect sizes, p-values, and q-values per term. Subset to genes/celltypes of interest first (`cds_subset <- cds[rowData(cds)$gene_short_name %in% genes, ]`) for speed. This is the model-based DE analog of scanpy's rank_genes_groups and is well-suited to condition/disease contrasts.

## Trajectory and Pseudotime Analysis
Purpose: Model a SINGLE continuous developmental or differentiation process (progenitor → intermediate → mature). ⛔ ONLY appropriate for one coherent lineage. DO NOT run pseudotime/trajectory across multiple distinct cell-type clusters or biologically unrelated populations (e.g. germ + stroma + epithelium together) — monocle3 builds a separate principal graph per partition, so `order_cells` assigns valid pseudotime only within the rooted partition and gives every other cell `Inf` (a silent, invalid result). Before trajectory, confirm the subset is one lineage (`table(colData(cds_sub)$assigned_cell_type)`) and a single partition (`length(unique(partitions(cds_sub))) == 1`); if it is a mix of cell types, use composition/marker/DE analyses instead of trajectory.
learn_graph: `cds <- learn_graph(cds)` fits a principal graph over the UMAP embedding (requires `cluster_cells` first, since it uses partitions).
order_cells: `cds <- order_cells(cds, root_pr_nodes = <node>)` (or `root_cells = <cell_ids>`) assigns each cell a pseudotime along the learned graph; retrieve with `pseudotime(cds)`. Choose a biologically motivated root (presumed progenitor). Visualize with `plot_cells(cds, color_cells_by = "pseudotime")` and inspect individual genes over pseudotime with `plot_genes_in_pseudotime(cds_subset)`.
graph_test: `graph_test(cds, neighbor_graph = "principal_graph")` (requires `learn_graph`) finds genes whose expression varies along the trajectory (Moran's I spatial autocorrelation); `neighbor_graph = "knn"` instead tests variation across the kNN graph (requires only `reduce_dimension`). Returns a data.frame with `morans_I`, `p_value`, `q_value`. Co-regulated genes can then be grouped into modules with `find_gene_modules(cds[sig_genes, ])`.

## Gene Set / Signature Scoring
Purpose: Quantify expression of a gene set (pathway, cell-cycle, signature) per cell.
There is no single monocle3 scoring call; compute it from the expression matrix. Aggregate a gene set with `aggregate_gene_expression(cds, gene_group_df = <data.frame mapping gene_id -> set>)`, or pull the matrix via `exprs(cds)` / `normalized_counts(cds)` and compute a mean (minus a random reference set) per cell with base R / Matrix operations, then store it as a new `colData(cds)$score` column for plotting.

## Composition / Proportion Analysis
Purpose: Quantify how cell types / clusters are distributed across conditions, samples, or genotypes — a primary comparative analysis in this lab. Build a data.frame from colData (`md <- as.data.frame(colData(cds))`) and plot stacked AND filled bar charts (`ggplot(md, aes(treatment, fill = assigned_cell_type)) + geom_bar(position = "stack")` for counts and `position = "fill"` for proportions; flip the aesthetics to also see condition-within-celltype). Tabulate the contingency table (`table(md$assigned_cell_type, md$treatment)`) with `knitr::kable`, and test the shift statistically with `chisq.test`/`fisher.test` on that table. This directly answers "does treatment change the cellular makeup?".

## Visualization
Purpose: Plot results (embeddings, marker expression, QC) to interpret data. All plots are ggplot2 objects — print them to render inline.
plot_cells: the workhorse — `plot_cells(cds, color_cells_by = "clusters")`, `plot_cells(cds, color_cells_by = "pseudotime")`, `plot_cells(cds, genes = c("GENE1", "GENE2"), scale_to_range = FALSE, show_trajectory_graph = FALSE, cell_size = 0.5)` (colors by expression, faceted per gene), with `label_cell_groups`, `show_trajectory_graph`, `group_label_size`; add `+ theme_bw() + facet_wrap(~treatment)` to compare across conditions.
plot_genes_violin: the lab's go-to for per-group expression — subset to genes first (`plot_genes_violin(cds[rowData(cds)$gene_short_name %in% genes, ], group_cells_by = "assigned_cell_type", log_scale = FALSE)`), one panel per gene; facet by condition to compare.
plot_genes_by_group: dotplot of mean expression × fraction expressing for selected genes across a grouping (cluster/celltype).
plot_genes_in_pseudotime: expression of selected genes as a function of pseudotime.
plot_pc_variance_explained / plot_percent_cells_positive: QC and composition.
For anything custom, extract data from `colData(cds)`, `rowData(cds)`, `reducedDims(cds)`, or `exprs(cds)` into a data.frame and build the figure directly with ggplot2 (`ggplot(...) + geom_*`). Combine multiple panels with patchwork (`p1 + p2`) or `cowplot::plot_grid`. Always print the final plot object so it renders inline.
